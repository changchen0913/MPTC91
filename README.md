# MPTC 91 週年紀念禮盒

憲兵訓練中心 91 週年紀念禮盒的互動 3D 網頁。使用者可以直接用滑鼠拖開盒蓋，拿起盒內的三樣紀念品翻轉端詳。

**線上瀏覽：** https://changchen0913.github.io/MPTC91/

以 [Three.js](https://threejs.org/) r180 製作。禮盒、玻璃杯、滑鼠墊等模型全部由程式即時生成，沒有外部 3D 模型檔；three.js 與所有圖片素材都內含在 repo 裡，執行時不需要連外。

## 操作方式

畫面上刻意不放操作按鈕，所有動作都在 3D 場景裡直接完成。

| 動作 | 操作 |
| --- | --- |
| 開闔盒蓋 | 直接拖曳盒蓋，蓋子會跟著游標走；放手後依拖曳方向與幅度自動開到底或闔上。輕點盒蓋也可開關。 |
| 旋轉視角 | 拖曳盒蓋以外的任何地方 |
| 縮放 | 滑鼠滾輪 |
| 拿起產品 | 開盒後點選產品，鏡頭會推近特寫 |
| 翻轉產品 | 特寫狀態下拖曳 |
| 放回 | 點「放回禮盒」或按 <kbd>Esc</kbd> |
| 展開滑鼠墊 | 特寫滑鼠墊時點「展開滑鼠墊」 |

鍵盤操作者按 <kbd>Tab</kbd> 會浮出一列控制鈕（開闔盒蓋、選擇產品），平時視覺上隱藏，不佔版面。

## 本機執行

需要 Node.js 20 以上。

```bash
npm start
```

然後開啟 http://127.0.0.1:4173 。Windows 使用者也可以直接雙擊「開啟禮盒.cmd」，它會啟動伺服器並開啟瀏覽器；**關閉那個主控台視窗即停止伺服器**。

> 必須透過網頁伺服器開啟。直接用 `file://` 雙擊 HTML 不會動——瀏覽器會以 CORS 為由封鎖 ES module 的載入，而且本機圖片會污染 canvas，導致貼圖處理失敗。頁面偵測到這個情況時會顯示說明，而不是卡在載入畫面。

## 部署

`docs/` 就是完整的靜態網站，沒有建置步驟。

- **GitHub Pages**：Settings → Pages → Source 選 `main` 分支的 `/docs` 資料夾。
- **其他靜態主機**：把 `docs/` 內容整組上傳到根目錄即可。

## 目錄結構

```
docs/                    完整靜態網站（GitHub Pages 發佈來源）
├── index.html
├── app.js               全部場景與互動邏輯
├── style.css
├── assets/              封面美工稿、產品照、木紋、Logo
└── vendor/              three.js r180 與 OrbitControls 等 addon
server.cjs               本機靜態伺服器
開啟禮盒.cmd              Windows 一鍵啟動
使用說明.md               給非技術使用者的說明
```

產品文案與規格集中在 `app.js` 最上方的 `data` 陣列，要改文字不必碰場景程式。

## 技術筆記

**尺寸**　模型統一使用「每公分 0.25 場景單位」。外盒 15 × 26.5 × 高 10 公分、咖啡包 10.1 × 8.2 公分（6 入）、玻璃杯直徑 8.2 × 高 9.5 公分、滑鼠墊 25 × 30 公分。壁厚、包裝厚度與內襯間距為展示用估算，不是製造圖。

**盒蓋拖曳**　把游標射線與「抓取點所在的那片 z 平面」求交，再換算成繞鉸鏈軸的角度，所以蓋子是真的跟著手指走，而不是把位移量換算成轉速。角度會做跨 ±π 的相位解纏，避免拉過頭時整個蓋子瞬間翻回去。視角太接近軸向時（射線 z 分量過小）會放棄接管拖曳，讓它退回成一般的視角旋轉。

**封面貼圖**　`assets/cover.png` 是平面美工稿。程式依亮度把稿子的黑底去背，只留下燙金線條與徽記，底下直接透出盒身自己的顆粒材質——直接整張貼上去會變成一塊浮在盒面上的貼紙。金色區域另外萃取成 metalness map，讓燙金有金屬反光。

**玻璃杯**　杯身用 `LatheGeometry` 車出剖面，杯底的立體山形是程式生成的高度場（三個高斯峰值疊加，再加上正弦噪聲做細部起伏），外層用 `MeshPhysicalMaterial` 的透射與 clearcoat 模擬玻璃。

**滑鼠墊**　同一張網格用參數化曲率在「捲成圓柱」與「完全攤平」之間連續變形，逐頂點計算位置；邊緣車縫線是跟著網格邊界即時重算的 `LineLoop`。

**內襯**　用 `ExtrudeGeometry` 搭配 `Shape` 的 holes 一次擠出三個置物格。

**打光**　三盞 `RectAreaLight`（主光箱、側邊條燈、正面補光）負責質感，另一盞 `DirectionalLight` 負責 VSM 軟陰影；環境光用 `RoomEnvironment` 經 PMREM 產生。
